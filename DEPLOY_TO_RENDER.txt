DEALGUARD - RENDER DEPLOYMENT

1. Extract this ZIP on your computer.
2. Upload the CONTENTS of this folder to a new GitHub repository (not the enclosing folder).
3. In Render, choose New > Web Service and connect that GitHub repository.
4. Use these settings:
   Runtime: Python
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn app:app
5. Add environment variable DEALGUARD_SECRET_KEY with a long random secret value, or use the generated value in render.yaml if deploying with a Blueprint.
6. Deploy. Render will provide a public URL.

Important: The website code currently expects optional category_price_reference.csv beside app.py for category-based reference checks. This CSV was not included in the supplied website ZIP, so that check will show Reference Data Unavailable until the correct project CSV is added. Do not add price_reference.csv in its place; it has a different format.

The Colab proxy URL is temporary. A Render deployment runs independently of Colab.
